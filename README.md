# BuddyScript

A production-ready social media platform with real-time updates and secure authentication.

## ✨ Features
- **Secure Authentication**: Transitioned to HttpOnly Cookie-based authentication for enhanced security.
- **Real-time Engine**: Powered by Socket.io with Redis adapter for scalable post engagement and notifications.
- **Content Auditing**: Integrated reporting system for post and comment moderation.
- **Modern UI**: Facebook-style layout with relative timestamps and localized engagement rooms.

## 🛠️ Project Structure
- `backend/`: Node.js/Express server with MongoDB.
- `frontend/`: React with Vite.

## 🚀 Getting Started
1. Install dependencies in both folders: `npm install`.
2. Configure `.env` files (refer to `.env` in respective directories).
3. Run the application: `npm run dev`.
